# 🏥 Hospital Management System

A menu-driven **Hospital Management System** developed using C programming to manage basic patient records. The application allows hospital staff to admit patients, view patient details, and manage patient discharges using file handling for persistent data storage.

### ✨ Key Features

- **Patient Admission:** Register new patients by entering their ID, name, address, and disease.
- **Patient Records:** View the complete list of admitted patients along with their details and admission dates.
- **Patient Discharge:** Discharge patients using their unique patient ID and remove their records from the file.
- **Automatic Date Tracking:** Capture the patient's admission date using the system date.
- **Persistent Storage:** Store patient records in files so that data is retained between program executions.

### 🛠️ Tech Stack

- **Programming Language:** C
- **Data Storage:** File Handling (`patient.txt`)
- **Core Concepts:** Structures, Pointers, Functions, File I/O, and Conditional Statements.
- **Libraries:** `stdio.h`, `stdlib.h`, `string.h`, `time.h`, `conio.h`
